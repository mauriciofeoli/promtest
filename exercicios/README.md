# Exercícios

Os exercícios de código feitos nas sessões de estudo, separados por módulo. Cada arquivo pratica um conceito. Os exemplos usam situações de QA, como casos de teste, suítes e falhas.

O projeto de cada módulo fica em [`projetos/`](../projetos/). Aqui ficam só os exercícios menores do caminho.

## Como rodar

Com o Python instalado (veja [docs/SETUP.md](../docs/SETUP.md)):

```bash
cd exercicios/modulo-01-base/python
python veredito.py
```
