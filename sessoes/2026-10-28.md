## O que estudei

- Revisão: `SyntaxError` faz o arquivo não rodar nem a primeira linha; `"Login" == "login"` é `False` (maiúsculas importam); `"PASS" != "FAIL"` é `True`; escolher dados de teste em que cada valor da saída dê um número diferente.
- `for item in lista:`: repete as linhas recuadas uma vez para cada item; para sozinho quando a lista acaba.
- Contador: variável que começa em 0 antes do `for` e recebe `total = total + 1` a cada volta.
- `if` dentro do `for` para contar só os itens que atendem uma condição (recuo em degraus).
- Comentário separa blocos para quem lê, mas o Python roda o arquivo inteiro de cima a baixo.
