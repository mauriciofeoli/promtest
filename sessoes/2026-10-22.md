## O que aprendi (com minhas palavras)

- Um script é um arquivo de texto `.py` que o Python lê de cima para baixo.
- `print("texto")` mostra uma linha na tela; texto vai entre aspas e se chama string.
- Com erro de sintaxe, o Python não roda nem a linha 1: ele confere o arquivo inteiro antes de começar.
- A mensagem de erro diz o arquivo, a linha, aponta o lugar com `^` e diz o tipo do erro na última linha.
